# Mood Harmony

Mood Harmony is a web application designed to help users discover and enjoy music based on their mood. By integrating with the Deezer API, the app provides personalized playlists, song recommendations, and a smooth, intuitive interface for music exploration.

## Features

- **Mood-Based Music Discovery**: Select your current mood and receive curated playlists that match it.
- **Search and Explore**: Find songs, albums, and artists with real-time suggestions.
- **Deezer API Integration**: Access a wide range of music content directly from Deezer.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: (If applicable) Node.js / Express or Flask
- **API**: Deezer Music API
- **Deployment**: Replit (live demo URL available)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Snooz4pm/Mood-Harmony.git
````

2. Navigate to the project directory:

   ```bash
   cd Mood-Harmony
   ```
3. Install dependencies (if backend exists):

   ```bash
   npm install  # for Node.js
   pip install -r requirements.txt  # for Python/Flask
   ```
4. Run the app:

   ```bash
   npm start  # Node.js
   python app.py  # Flask
   ```
5. Open your browser at `http://localhost:3000` (or the port specified by Replit).

## Usage

1. Open the app in your browser.
2. Select your mood or enter a search term.
3. Browse the generated playlists or recommended songs.
4. Click play to preview songs directly in the interface.
